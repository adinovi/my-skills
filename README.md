## 🚀 Getting Started

To use these skills with your AI assistant:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/adinovi/my-skills.git
    ```
2.  **Import into your Agent**:
    Point your agent's skill search path to the specific skill directory or the root `skills/` folder.
3.  **Follow individual skill setup**:
    Each skill has its own `README.md` and `SKILL.md` with specific configuration instructions.
